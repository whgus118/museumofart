# [PRD] 미술관 웹사이트 디지털 접근성 개선 프로젝트

**버전:** 1.1  
**상태:** 최종 Draft  
**대상:** 박복순 어르신 (72세, IT 숙련도 최하)  
**작성일:** 2026-03-27

---

## 1. 프로젝트 배경

현재 미술관 웹사이트 메인 페이지는 별도의 안내 영역 없이 **대형 배너 이미지** 위주로만 구성되어 있습니다. 이러한 미니멀한 구성은 젊은 층에게는 깔끔해 보일 수 있으나, 고령 사용자에게는 **'어디가 클릭 가능한 버튼인지'**, **'원하는 정보가 어디에 숨어 있는지'** 알 수 없게 만드는 높은 진입장벽이 됩니다. 공공기관으로서 모든 연령층이 타인의 도움 없이 스스로 전시를 예약하고 편의시설을 찾을 수 있도록 **'친절하고 직관적인 도슨트형 UI'**로 리디자인하고자 합니다.

## 2. 문제 정의 (Key Pain Points)

- **시각적 피드백 부재:** 배너 포스터나 화살표에 마우스를 올려도 커서 변화나 시각적 응답이 없어 조작의 확신을 얻지 못함.
- **좁은 인터랙션 범위:** GNB 및 LNB의 호버 효과가 텍스트에만 국한되어, 정밀한 마우스 제어가 어려운 사용자의 오작동 유발.
- **배너 제어권 상실:** 메인 배너가 자동으로 넘어가지만 **일시정지 버튼**이 없어, 정보를 충분히 읽지 못한 채 화면이 바뀌어 버리는 당혹감 발생.
- **인지적 미로:** '편의시설'이라는 직관적인 단어 대신 '미술관소개 > 특정 미술관 > 시설별 이용안내'로 이어지는 깊은 단계(Depth)와 모호한 명칭으로 인해 정보 탐색 중 길을 잃음.

## 3. 핵심 UX 가설

> **"배너와 메뉴의 반응 영역을 '면(Area)' 단위로 확장하고, 자동 재생 제어권과 직관적인 단축 경로를 제공한다면, 고령 사용자가 느끼는 디지털 위축감이 해소되고 과업 성공률이 높아질 것이다."**

## 4. 타겟 페르소나

- **이름:** 박복순 (72세)
- **IT 숙련도:** 최하 (마우스 화살표를 자주 놓치며, 텍스트와 버튼의 구분을 어려워함)
- **이용 목적:** 손주와의 나들이를 위한 어린이 전시 예약 및 휴게석/엘리베이터 위치 확인
- **Pain Point:** "그림은 예쁜데 어디를 눌러야 할지 모르겠고, 화면이 제멋대로 움직여서 무섭다."

## 5. 핵심 요구사항 및 기능 명세

### 5.1 시각적 피드백 및 클릭 영역 최적화

- **[REQ-01] 너그러운 인터랙션 영역:** GNB 및 LNB 메뉴는 글자가 아닌 **텍스트를 포함한 박스 전체 영역**에 호버 및 클릭 효과를 적용한다.
- **[REQ-02] 즉각적 시각 응답:** 메인 배너 포스터 마우스 오버 시 **이미지 선명도 변화 및 손가락 커서(Pointer)**를 즉시 노출한다.
- **[REQ-03] 화살표 조준 보정:** 슬라이드 이동 화살표는 실제 크기보다 넓은 **투명 클릭 영역(최소 44x44px)**을 설정하여 조작 성공 경험을 제공한다.

### 5.2 메인 배너 제어 및 인지 강화

- **[REQ-04] 배너 일시정지 기능:** 배너 하단 네모난 블록(인디케이터) 영역 옆에 명확한 형태의 **'일시정지' 버튼**을 추가하여 사용자가 화면을 멈춰 세울 수 있게 한다.
- **[REQ-05] 브레드크럼(위치 알림):** 페이지 이동 시 현재 위치(홈 > 교육 > 예약)를 상단에 큰 글씨로 노출하여 심리적 안도감을 준다.

### 5.3 정보 구조 및 경로 혁신

- **[REQ-06] 행동 중심 명칭:** '교육' 메뉴 옆에 **(예약/신청)** 보조 문구를 병기하여 예약 메뉴를 찾는 인지적 과부하를 줄인다.
- **[REQ-07] 편의시설 퀵 메뉴:** 3단계의 복합 경로와 '시설별 이용안내'라는 모호한 말 대신, 메인 우측에 **'의자/엘리베이터' 아이콘 기반 퀵 메뉴**를 배치하여 즉시 접근을 지원한다.

## 6. 성공 측정 지표 (KPI)

- **수행 속도:** 메인 접속 후 편의시설(의자/엘리베이터) 위치 확인까지 걸리는 시간 50% 단축.
- **조작 성공률:** 배너 및 메뉴 클릭 시 발생하는 오클릭(배경 클릭 등) 횟수 40% 감소.
- **사용자 만족도:** 고령 사용자 대상 UT 진행 시 "화면 제어가 쉽고 메뉴가 명확하다"는 긍정 피드백 80% 이상 확보.
